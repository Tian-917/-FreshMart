# 会员端小程序 · 启动说明

## 1. 这是什么

`frontend/miniprogram` 是一个**原生微信小程序**工程（不是 uni-app、不依赖任何模板），
按鲜达超市后端 `/user/**` 接口手写，共 8 个页面：

| 页面 | 路径 | 主要接口 |
| --- | --- | --- |
| 首页 | `pages/index/index` | `/user/category/list`、`/user/product/list`、`/user/cart/list`、`/user/store/status` |
| 商品详情 | `pages/product/product` | `/user/product/{id}`（含实时库存）、`/user/cart/add` |
| 购物车 | `pages/cart/cart` | `/user/cart/list`、`/user/cart/add`、`/user/cart/sub`、`/user/cart/clean` |
| 结算下单 | `pages/checkout/checkout` | `/user/addressBook/default`、`/user/order/submit`（带幂等令牌）、`/user/order/payment` |
| 订单列表 | `pages/orders/orders` | `/user/order/historyTradeOrder`、`/user/order/cancel`、`/user/order/reminder`、`/user/order/repetition` |
| 订单详情 | `pages/orderDetail/orderDetail` | `/user/order/orderItem/{id}` |
| 地址管理 | `pages/address/address` | `/user/addressBook/*` |
| 我的 | `pages/mine/mine` | 本地会员信息 |

技术点：原生 WXML/WXSS/JS、`utils/request.js` 统一封装（自动带 `authentication` 头、401 清理登录态）、
tabBar 四页、下拉刷新、本地插画图（`static/goods`、`static/icons`，不依赖 OSS）、
商品售罄标记（`stock <= 0`）、下单幂等令牌（进入结算页生成，网络重试不会重复建单）。

## 2. 启动步骤

### 2.1 先起后端（必须）

```powershell
# 1. Redis
Start-Process '<Redis 目录>\redis-server.exe' -WorkingDirectory '<Redis 目录>'
# 2. 项目
cd <项目根目录>
java -jar freshmart-server\target\freshmart-server-1.0-SNAPSHOT.jar
```

数据库里要有生鲜货盘（21 个商品 + 类目 + 演示订单）：

```powershell
mysql -uroot -p < sql/seed_catalog.sql
```

### 2.2 导入小程序

1. 打开**微信开发者工具** → 导入项目
2. 目录选 `frontend/miniprogram`
3. AppID：填你自己的（或选「测试号」）；`project.config.json` 里的 `appid` 已打码成 `******`，必须换掉才能编译
4. 右上角 **详情 → 本地设置** → 勾选 **「不校验合法域名、web-view、TLS 版本以及 HTTPS 证书」**
   （文件里已设 `urlCheck: false`，一般不用手动改）
5. 点**编译**

首页应显示：门店条（营业中）+ 6 个类目 + 商品两列网格。

> 改了代码或图片后如果没生效：**工具 → 清缓存 → 全部清除**，再编译。

### 2.3 登录不用管

`application-dev.yml` 里 `freshmart.wechat.dev-login: true`，
后端会跳过微信 `code2session`，用固定演示会员 `dev_openid_demo` 登录，
所以不需要真实 AppID/Secret 就能把整条链路跑通。

要接真实微信登录时：

```powershell
$env:FRESHMART_WX_APPID='你的appid'
$env:FRESHMART_WX_SECRET='你的secret'
$env:FRESHMART_WX_DEV_LOGIN='false'
```

## 3. 一次完整演示路径

1. 首页 → 点类目「时令蔬菜」 → 点「有机西兰花 300g」
2. 详情页选规格 `500g` → 加入购物车
3. 底部购物车条 → 购物车 → 调整数量
4. 去结算 → 选地址（默认地址已由 seed 脚本写入）→ 填备注 → 提交订单
5. 支付页直接成功（后端是模拟支付）→ 跳到订单列表，状态「待拣货」
6. 在门店后台（Knife4j 或管理端）把它「接单 → 派送 → 完成」，小程序里催单/再来一单都能用

## 4. 目录结构

```
freshmart-mp
├── app.js              登录（wx.login → /user/user/login → 存 token）
├── app.json            8 个页面 + 4 个 tabBar
├── app.wxss            设计变量与通用样式
├── project.config.json urlCheck: false
├── utils/request.js    统一请求封装
├── pages/              8 个页面（js + wxml，公共样式在 app.wxss）
└── static/
    ├── goods/          22 张实拍商品图（DB 里默认指向 OSS，这里作离线兜底）
    └── icons/          类目与空状态图标
```

## 5. 常见问题

| 现象 | 处理 |
| --- | --- |
| 首页空白、toast「连不上后端」 | 后端没起，或端口不是 8080；确认 `Test-NetConnection 127.0.0.1 -Port 8080` |
| 图片不显示 | 图片路径是项目内绝对路径 `/static/goods/xxx.png`，不要在开发者工具里改「基础库」以外的东西；图片文件已随工程提供 |
| 401 / 登录过期 | 我的 → 重新登录；或清缓存后重新编译 |
| 商品列表是空的 | 数据库没跑 `seed_catalog.sql`，或类目与商品不匹配 |
| 华为/安卓真机预览连不上 | 手机和电脑同一局域网，把 `utils/request.js` 里 `BASE_URL` 改成电脑 IP，例如 `http://192.168.1.8:8080` |
